## Public interface

```ts
// languages/index.ts
export const EXTRACTORS: Partial<Record<Language, LanguageExtractor>>;

// tree-sitter-types.ts — THE contract every language config implements
interface LanguageExtractor {
  preParse?: (source: string, filePath?: string) => string;   // MUST preserve byte offsets
  functionTypes: string[]; classTypes: string[]; methodTypes: string[];
  interfaceTypes: string[]; structTypes: string[]; enumTypes: string[];
  enumMemberTypes?: string[]; typeAliasTypes: string[]; importTypes: string[];
  callTypes: string[]; variableTypes: string[]; fieldTypes?: string[]; propertyTypes?: string[];
  nameField: string; bodyField: string; paramsField: string; returnField?: string;
  resolveName?: (node, source) => string | undefined;
  recoverMangledName?: (name: string) => string;              // C/C++ only
  extractPropertyName?: (node, source) => string | null;
  getSignature?: (node, source) => string | undefined;
  getVisibility?: (node) => 'public'|'private'|'protected'|'internal'|undefined;
  isExported?/isAsync?/isStatic?/isConst?: (node) => boolean;
  extractModifiers?: (node) => string[] | undefined;           // → Node.decorators
  extraClassNodeTypes?: string[]; methodsAreTopLevel?: boolean; // Go: true
  skipBodilessClass?: boolean;                                 // C++ only (#1093)
  interfaceKind?: NodeKind;                                    // Rust/Scala:'trait', ObjC:'protocol'
  visitNode?: (node, ctx: ExtractorContext) => boolean;        // true = fully handled
  synthesizeMembers?: (classNode, ctx) => void;                // Java Lombok only
  classifyClassNode?: (node) => 'class'|'struct'|'enum'|'interface'|'trait';
  classifyMethodNode?: (node) => 'method'|'property';          // TS/JS #808
  resolveBody?: (node, bodyField) => SyntaxNode | null;
  extractImport?: (node, source) => ImportInfo | null;         // {moduleName, signature, handledRefs?}
  extractVariables?: (node, source) => VariableInfo[];
  getReceiverType?/getReturnType?: (node, source) => string | undefined;
  resolveTypeAliasKind?: (node, source) => NodeKind | undefined;
  isMisparsedFunction?: (name, node) => boolean;
  extractBareCall?: (node, source) => string | undefined;      // Ruby, Dart
  packageTypes?: string[]; extractPackage?: (node, source) => string | null;
}

interface ExtractorContext {                 // callback surface given to hooks
  createNode(kind, name, node, extra?: Partial<Node>): Node | null;
  visitNode(node): void;  visitFunctionBody(body, functionId): void;
  addUnresolvedReference(ref: UnresolvedReference): void;
  pushScope(nodeId): void;  popScope(): void;
  readonly filePath: string; readonly source: string;
  readonly nodeStack: readonly string[]; readonly nodes: readonly Node[];
}

// Standalone extractors (all: constructor(filePath, source); extract(): ExtractionResult)
export class SvelteExtractor { extract(): ExtractionResult }
export class VueExtractor    { extract(): ExtractionResult }
export class LiquidExtractor { extract(): ExtractionResult }
export class DfmExtractor    { extract(): ExtractionResult }
// ExtractionResult = { nodes: Node[]; edges: Edge[]; unresolvedReferences: UnresolvedReference[];
//                      errors: ExtractionError[]; durationMs: number }

// Exported pre-parse helpers (unit-tested individually, c-cpp.ts / csharp.ts / vbnet.ts):
export function blankCppExportMacros/blankCppInlineMacros/blankCppApiPrefixMacros/
  blankCppAnnotationMacroCalls/blankCppInlineAnnotationMacros/blankMetalAttributes/
  blankCudaConstructs/recoverMangledCppName/normalizeCppReturnType/stripCppTemplateArgs(source|name): string;
export function blankCsharpPreprocessorDirectives(source: string): string;
export function ensureTrailingNewline(source: string): string;
export function classifyTsClassMember(node): 'method'|'property';
```

Dispatch (in `tree-sitter.ts::extractFromSource`): language `svelte`→SvelteExtractor, `vue`→VueExtractor, `astro`→AstroExtractor, `liquid`→LiquidExtractor, `razor`→RazorExtractor, `xml`→MyBatisExtractor, `cfml|cfscript`→CfmlExtractor, `yaml|twig|properties`→empty result (file-level only), `pascal` + ext `.dfm|.fmx`→DfmExtractor, else `TreeSitterExtractor(filePath, source, language)` using `EXTRACTORS[language]`.

## Key algorithms & data flow

**Generic pipeline** (context; core lives in `tree-sitter.ts`): `preParse(source)` → parse with grammar → walk AST; node types matched against the config's `*Types` lists dispatch to extractFunction/Class/Method/… which call the hooks; `visitNode` hook runs FIRST and short-circuits when it returns true. Calls inside bodies become `UnresolvedReference{referenceKind:'calls'}`; imports become `import` nodes + `imports` refs; `packageTypes` wraps top-level decls in a `namespace` node (qualified names `pkg::Class::method`).

**Grammar table** (`WASM_GRAMMAR_FILES`) — tree-sitter-wasms package unless *vendored* in `src/extraction/wasm/` (set `VENDORED_WASM_LANGS = {pascal, scala, lua, luau, csharp, r, cfml, cfscript, cfquery, cobol, vbnet, erlang, terraform, arkts, nix}`): typescript/tsx/javascript(+jsx)/python/go/rust/java/c/cpp/c_sharp/php/ruby/swift/kotlin/dart/pascal/scala/lua/r/luau/objc/cfml/cfscript/cfquery/cobol/vbnet/erlang/solidity/terraform/arkts/nix → `tree-sitter-<name>.wasm`. Grammars load lazily and **sequentially** (web-tree-sitter WASM race, tree-sitter#2338). SFC languages expand: svelte/vue/astro pull in typescript+javascript; cfml pulls in cfscript+cfquery.

**Per-language highlights** (NodeKinds/EdgeKinds beyond the generic function/method/class/interface/struct/enum/enum_member/type_alias/import/variable + contains/calls/imports):

- **TS/JS**: `classifyTsClassMember` — a `public_field_definition`/`field_definition` is a *method* only if a named child is `arrow_function`/`function_expression` or a `call_expression` whose arguments contain one (HOF wrapper `throttle(()=>…)`); else *property*. `isExported`: walk parent chain for `export_statement`. `isConst`: `lexical_declaration` with a `const` child. Import module: `source` field, quotes stripped via `/['"]/g`.
- **Go**: `methodsAreTopLevel:true`; receiver from `receiver` field text via regex `/\(\s*(?:[A-Za-z_]\w*\s+)?\*?\s*([A-Za-z_]\w*)/` (#583 generics); exported = name char in A–Z; `type_spec`→struct/interface via inner `struct_type`/`interface_type`; return type: unwrap multi-return first element, pointer `*Foo`→`Foo`, strip `<…>`/`[…]`, last `.` segment, must match `/^[A-Za-z_]\w*$/`.
- **Rust**: traits (`interfaceKind:'trait'`), `function_signature_item` (bodiless trait methods) extracted; receiver = last `type_identifier` child of enclosing `impl_item` (or inner ident of `generic_type`); `-> Self` → marker string `'self'`; use-declaration → root crate segment (recursing scoped_identifier; `crate`/`super`/`self` kept).
- **Java**: `annotation_type_declaration` as interface; `isConst` = modifiers contain both `\bstatic\b` and `\bfinal\b`; Lombok synthesis (below); package via `package_declaration` → `scoped_identifier|identifier`.
  - **Lombok** (`synthesizeMembers`): annotations `Getter/Setter/Data/Value/Builder/SuperBuilder/ToString/EqualsAndHashCode` + log set `{Slf4j, Log4j, Log4j2, Log, CommonsLog, JBossLog, Flogger, XSlf4j, CustomLog}`. Getter `getX` (`isX`/keep `isFoo` for primitive boolean), setter `setX` (boolean `isFoo`→`setFoo`); skips static fields; setters skip final; `builder()` static returning `<Class>Builder`; `toString`/`equals(Object o)`/`hashCode`; `log` field `Logger log` private static. All carry `visibility:'public'`, `decorators:['lombok']`, `docstring:'Lombok-generated (@Ann)'`; never overrides an explicitly declared member (`takenMethods`/`takenFields` keyed on `classQN::name`).
- **C** (`cExtractor`): structs/enums/typedef; `isConst` = named child `type_qualifier` with text `const`; content-gated CUDA blank in preParse; `recoverMangledName` shared with C++.
- **C++** (`cppExtractor`): `skipBodilessClass:true`; name via `qualified_identifier` BFS skipping `parameter_list`/`trailing_return_type`; receiver = qualifier segments joined `::`; macro-defined-name recovery `MACRO_NAME(real_name,…)` — name regex `/^[A-Z][A-Z0-9]*(?:_[A-Z0-9]+)+$/`, first param lone `type_identifier` containing lowercase, no other lone-ident params; `isMisparsedFunction`: name starts `namespace`, is in `{switch,if,for,while,do,case,return}`, or macro-misparsed type decl (bodiless class/struct `type` + non-function_declarator). preParse chain (order matters): `blankCppExportMacros` (regex `/\b(class|struct)(\s+)([A-Z][A-Z0-9_]+)(?=\s+[A-Za-z_]\w*(?:\s+final)?\s*[:{])/g`) → `blankCppInlineMacros` (curated ~60-token list, longest-first alternation, lookahead `(?=\s+[A-Za-z_])`) → `blankCppApiPrefixMacros` (`/\b[A-Z][A-Z0-9_]*(?:_API|_EXPORT|_ABI)\b(?=\s+[A-Za-z_])/g`) → `blankCppInlineAnnotationMacros` (`UMETA|UPARAM|UE_DEPRECATED\w*` balanced-paren, string-aware) → `blankCppAnnotationMacroCalls` (line-leading `^[ \t]*[A-Z][A-Z0-9_]{2,}\s*\(`, balanced parens, next non-ws char must match `[A-Za-z_~#]`); then `.metal`→`blankMetalAttributes` (`/\[\[\s*[A-Za-z_]\w*(?:\s*\([^()\n]*\))?(?:\s*,\s*…)*\s*\]\]/g`); `.cu/.cuh` or `looksLikeCudaSource` (`__global__|__device__|__constant__|cudaStream_t`) → `blankCudaConstructs` (`__launch_bounds__(…)`, dunder specifiers, `<<<[^;]{0,400}?>>>` only when braces balance). ALL blanks replace with equal-length spaces, newlines preserved. Return type normalization: unwrap `unique_ptr|shared_ptr|weak_ptr|optional<T>`, strip cv/`<>`/`*&`, reject 27-entry primitive set. `recoverMangledCppName`: only for names containing whitespace, not `operator…`/`~…`, not `Ret (name)` idiom; take last token before `(`, reject 23-entry `CPP_PRIMITIVE_NAMES`.
- **C#**: preParse blanks `^([ \t]*)#[ \t]*(if|elif|else|endif)\b[^\n]*` per line (keeps both branches); records → class unless a `struct` keyword child; namespaces (block + file-scoped) as packageTypes; visibility default `'private'`; `isConst` = `const` or (`static`+`readonly`).
- **PHP**: include/require(`_once`) expressions as importTypes with static-string-literal paths only; class constants + trait `use` (→ `implements` refs) via visitNode; visibility default `'public'`; `self|static|$this` return → `'self'`; non-class return set of 19 lowercase names; file-level `namespace Foo\Bar;` only (braced form skipped).
- **Ruby**: mixins `include|extend|prepend` on receiverless `call` → `implements` refs from enclosing scope (args of type `constant`/`scope_resolution` only); `module` nodes via hook; `extractBareCall`: statement-level `identifier` whose parent ∈ `{body_statement,then,else,do,begin,rescue,ensure,when}`, skipping `{true,false,nil,self,super,__FILE__,__LINE__,__dir__}` and Constants.
- **Swift**: `classifyClassNode` by keyword child `struct`/`enum`; extension of nested type `extension KF.Builder` named by LAST segment (#750); return type positional (grammar labels both name and return as field `name`); visibility default `'internal'`, `fileprivate`→private; `isStatic` includes `class` keyword.
- **Kotlin**: no field names in grammar → `nameField:'simple_identifier'`, positional return type after `function_value_parameters`; properties via hook — scope walk: function body/lambda/init/getter/setter → local (skip); `companion_object|object_declaration` → `val`→constant/`var`→variable; `class_declaration` → field. `fun interface` misparse recovery (2 ERROR-node patterns); `classifyClassNode` by `interface`/`enum` keyword children; `extractModifiers` captures `expect`/`actual` platform modifiers; `Unit|Nothing` returns rejected.
- **Dart**: no call node — `extractBareCall` on `selector` nodes containing `argument_part`; chained factory encoding `` `${innerCallee}().${method}` `` only when chain head is capitalized; ctor validation `dartCtorInfo` (first ctor identifier must equal enclosing type name — guards `@override (T) m()` misparse); unnamed ctor skipped via `isMisparsedFunction` (body still visited); named ctor renamed to ctor name; `static_final_declaration` → constant with `= <first 100 chars>` signature; visibility by `_` prefix; async on sibling `function_body`.
- **Pascal**: node types `declProc/declClass/declIntf/declEnum/declType/declUses/exprCall/declField/declConst`; visibility via ancestor `declSection` keyword children `kPublic|kPublished|kPrivate|kProtected`; `isStatic` = `kClass` child. (Body traversal is a core-extractor special case, not in this file.)
- **Scala**: val/var via hook using `pattern` field; object vals → constant, class/trait/enum/given vals → field; `enum_case_definitions` → enum_member per `simple_enum_case|full_enum_case`; `extension_definition` body visited transparently; type-annotation refs emitted, skipping 15 builtin capitalized types; `this.type` returns rejected.
- **Lua/Luau**: `require(…)` claimed in visitNode → `import` node + `imports` ref (string content, `[[…]]` brackets stripped, or Roblox `script.Parent.Signal` → trailing field); `function t.f`/`t:m` → method with table as receiver; Luau adds `type_definition` and `isExported` = source slice starts `'export '` (7 chars).
- **R**: everything via hook. Constants: assignment ops LEFT `{<-,<<-,=}` RIGHT `{->,->>}`; import fns `{library,require,requireNamespace,loadNamespace}` + `source`; class fns `{setClass,setRefClass,R6Class,ggproto}`; generic fns `{setGeneric,setMethod}`; constant name regex `/^[A-Z][A-Z0-9._]*$/`. Class-call methods from `name = function` entries directly (ggproto) or inside `list(...)` (R5 `methods=`, R6 `public=`/`private=`); parent refs: ggproto 2nd positional identifier, `inherit =`, `contains =` → `extends`. Nested bodies walked via `ctx.visitNode` (NOT visitFunctionBody) so nested assignments re-enter the hook. Top-level assignments only for variables; class-idiom twin variables suppressed.
- **ObjC**: selector names joined `part:part:`; `class_implementation` reuses the `@interface`'s class node (search `ctx.nodes` by name+file+kind) or creates one; `@property` name dug from `struct_declarator`; `isStatic` = node text matches `/^\s*\+/`; return type skips 25-entry qualifier set, rejects `void|id|instancetype`; `interfaceKind:'protocol'`.
- **COBOL**: preParse detects free-format (marker regex `^([ \t]*)(IDENTIFICATION\s+DIVISION|ID\s+DIVISION|PROGRAM-ID\b|\d{2}[ \t]+[A-Za-z])` with indent < 7) → prefix line 0 with `'CGWIDE '`, others with 7 spaces; also `terminateSqlIncludes` writes a `.` after single-line `EXEC SQL INCLUDE x END-EXEC`. Program→`module`; section/paragraph headers→`function` (extents reconstructed to next header; sections signature `'SECTION'`); DATA DIVISION: level numbers drive scope stack (01/66/77 top-level, 88→`constant`, top→`variable`, nested→`field`; FILLER skipped); PERFORM/GO TO/CALL 'literal' → `calls`; EXEC mining regexes (`EXEC_CICS_PROGRAM_RE`, `EXEC_CICS_TRANSID_RE` → ref `cics-transid:XXXX` uppercased, `EXEC_SQL_INCLUDE_RE`, `VALUE_LITERAL_RE` for same-file data-name deref); write-site refs from MOVE(dst)/ADD(to,giving)/COMPUTE(left)/SUBTRACT(from|giving), skipping `SPECIAL_REGISTER_RE = /^(RETURN-CODE|SQLCODE|SQLSTATE|TALLY|EIB[A-Z-]+|DFH[A-Z-]+|WHEN-COMPILED|LENGTH|ADDRESS)$/i`. **Module-level mutable state**: none (all local); but Erlang's file-memos below.
- **VB.NET**: preParse appends `\n` if missing (grammar `_eof` bug); events → `field` nodes; `Sub New` → method named `'New'`; `resolveBody: node => node` (no body wrapper); callTypes include `array_access_expression` (parens ambiguity); case-insensitive modifier regexes; `isConst` = `Const` or `Shared`+`ReadOnly`; delegates as typeAliasTypes.
- **Erlang**: **module-level mutable memo state** (`exportsFile/exportsMemo`, `lastFnFile/lastFnName/lastFnId`) — consecutive same-name `fun_decl`s merge into one node (endLine extended, clauses attributed); exports from `export_attribute` `fa` children or `-compile(export_all)` → `'all'`; `-spec` above becomes signature (≤300 chars) and docstring anchor; `-define` → `constant`, replacement body's calls attributed to the macro node; `?MACRO` use sites via `macro_call_expr` callType; record_decl → `struct`+`field`s (no descent into type exprs); `spec`/`callback` subtrees consumed; `-behaviour(x)` → `implements`; `.app`/`.app.src` `{application,Name,Props}` tuple → `mod` ref (`references`) + `applications`/`included_applications` (`imports`); quoted atoms unquoted `/^'([\s\S]*)'$/`; module attribute is the namespace so remote `mod:f` matches `mod::f` qualified names.
- **Solidity**: contract/library→`class`, interface→`interface`, each with `extends` refs from `inheritance_specifier` ancestors (resolver reclassifies to `implements` by target kind); struct/enum members are direct children (no body field) → handled in hook; `enum_value`→enum_member by own text; `event_definition`/`error_declaration`→`field` nodes (signature ≤200 chars) so `emit X`/`revert X` resolve; callTypes include `emit_statement`, `revert_statement`, `modifier_invocation`; constructor/fallback/receive named synthetically (`'constructor'`, keyword text `fallback|receive`); signature rebuilt from direct `parameter` children (no `parameters` field); `external`→public.
- **Terraform**: all via hook on `block` nodes; header = first `identifier` child + `string_lit`/`identifier` labels. Emissions: `resource "T" "N"` → class named `T.N` qn `T.N`; `data` → class qn `data.T.N`; `module "M"` → module qn `module.M`; `variable "X"` → variable qn `var.X` isExported:true; `output "X"` → variable qn `output.X`; `provider "P"` → namespace qn `provider.P` (alias → name `P.alias`, qn `provider.P.alias`); `locals` attrs → constant qn `local.<name>`; `terraform` block ignored; `moved|import|removed|assert` → refs anchored to file node with `suppressScoped`. Reference qualification (`qualifyReference`): `var.X`, `local.X`, `module.M` (+ scoped `module.M:output.out`, `module.M:remote-output.X` for `.outputs.X`), `data.T.N`, default `head.attr0`; builtin heads `{each,count,self,path,terraform}` + keywords `{null,true,false}` skipped. Module wiring: local `./`/`../` source → `module.M:file` imports ref; each non-meta attr (`MODULE_META_ARGS={source,version,count,for_each,providers,depends_on}`) → `module.M:var.<attr>` ref. Provider selection (`provider =`/`providers = {…}` object vals) → `provider.<addr>` refs. `.tfvars` top-level attributes → `var.<name>` refs from file node.

### Standalone extractors (reimplement line-by-line)

**SvelteExtractor** (`.svelte`): (1) always creates a `component` node — name = filename minus `.svelte`, qn `${filePath}::${name}`, lines 1..N, `isExported:true`, language `'svelte'`. (2) Script blocks via regex `/<script(\s[^>]*)?>(?<content>[\s\S]*?)<\/script>/g`; TS if attrs match `/lang\s*=\s*["'](ts|typescript)["']/`; module if `/context\s*=\s*["']module["']/`. Content start line = newlines before match + newlines in opening tag (0-indexed; do NOT +1 — the content's leading `\n` is line 1 of content). Each block delegated to `TreeSitterExtractor(filePath, content, 'typescript'|'javascript')`; result nodes get `startLine/endLine += blockStart`, `language='svelte'`, and a `contains` edge from the component; edges' `line` and refs' `line` offset likewise, refs get `filePath`/`language` rewritten. (3) Template calls: compute covered ranges of `<script>`/`<style>` via `/<(script|style)(\s[^>]*)?>[\s\S]*?<\/\1>/g`; per uncovered line scan `{expr}` via `/\{([^}#/:@][^}]*)\}/g` (excludes `{#if}`, `{:else}`, `{/if}`, `{@html}`); within expr, calls via `/\b([a-zA-Z_$][\w$.]*)\s*\(/g`; skip runes set `{$props,$state,$derived,$effect,$bindable,$inspect,$host,$snippet}` and `{if,else,each,await}`; emit `calls` refs from component node (line 1-indexed, column = exprIndex+callIndex). (4) Template components: uncovered lines, `/<([A-Z][a-zA-Z0-9_$]*)\b/g` → `references` refs (column = index+1). (5) Finally filter ALL refs whose name is a rune. Errors caught → `{message:'Svelte extraction error: …', severity:'error', code:'parse_error'}`.

**VueExtractor** (`.vue`): identical skeleton to Svelte (component node named filename minus `.vue`, script-block regex/line math byte-identical, `isSetup` = `/\bsetup\b/` on attrs). No template-expression call scan, no rune filtering. Template components: same covered-range logic; tag regex `/<([A-Za-z][A-Za-z0-9_-]*)\b/g`; PascalCase kept as-is, kebab-case (contains `-`) converted `kebabToPascal` (split `-`, capitalize each), lowercase-no-hyphen skipped (HTML element); builtin set (checked AFTER conversion) `{Transition,TransitionGroup,KeepAlive,Suspense,Teleport,Component,Slot}` skipped; `references` refs from component node.

**LiquidExtractor** (`.liquid` + Shopify `templates/**.json`, `sections/*.json`): creates a `file` node (kind `'file'`, name = basename, qn = filePath). JSON path (`filePath.endsWith('.json')`): `JSON.parse`; for each unique `sections[key].type` string emit `references` ref to literal name `sections/<type>.liquid` (line 1, col 0); invalid JSON → silently nothing. Liquid path, 4 passes: (a) snippets `/\{%[-]?\s*(render|include)\s+['"]([^'"]+)['"]/g` → per match: an `import` node (name=snippet, qn `${filePath}::import:${name}`, signature=fullMatch) + `contains` edge, a `component` node (name=snippet, qn `${filePath}::${tagType}:${name}`) + `contains` edge, and a `references` ref to `snippets/<name>.liquid`; (b) sections `/\{%[-]?\s*section\s+['"]([^'"]+)['"]/g` → same triple with qn `…::section:<name>` and ref `sections/<name>.liquid`; (c) schema `/\{%[-]?\s*schema\s*[-]?%\}([\s\S]*?)\{%[-]?\s*endschema\s*[-]?%\}/g` → one `constant` node, name from parsed JSON `.name` (string, or `.name.en`, or first value, fallback `'schema'`), qn `${filePath}::schema:${name}`; **deliberately no docstring** (security #383 — schema JSON may leak keys); (d) assigns `/\{%[-]?\s*assign\s+(\w+)\s*=/g` → `variable` nodes qn `${filePath}::${name}` + `contains`. Line = count of `\n` before index + 1; column = index − line start.

**DfmExtractor** (`.dfm`/`.fmx`, routed when detected language is `pascal`): creates a `file` node with `language:'pascal'`. Line-by-line state machine with a containment stack seeded `[fileNodeId]`. Patterns: `objectPattern = /^\s*(object|inherited|inline)\s+(\w+)\s*:\s*(\w+)/` → `component` node (name = 2nd group, signature = type name 3rd group, qn `${filePath}#${name}`, start/end = this line) + `contains` edge from stack top, then push; `eventPattern = /^\s*(On\w+)\s*=\s*(\w+)\s*$/` → `references` ref from stack top to the method name; `endPattern = /^\s*end\s*$/` → pop (never below 1). Multi-line property skip: a line ending `=\s*\(\s*$` starts a skip until a line ends with `)`; a line ending `=\s*<\s*$` skips until `>` — this is why `item … end` inside `Panels = <…>` doesn't pop the stack.

## Wire/contract surfaces

- **NodeKind/EdgeKind strings** (src/types.ts) are the DB/wire contract; extractors emit exactly: nodes `file, module, class, struct, interface, trait, protocol, function, method, property, field, variable, constant, enum, enum_member, type_alias, namespace, import, component`; refs/edges `contains, calls, imports, extends, implements, references`.
- **Node IDs**: `generateNodeId = '<kind>:' + sha256(`${filePath}:${kind}:${name}:${line}`).hex.slice(0,32)` — standalone extractors call it directly; must match byte-for-byte.
- **Qualified-name spellings** are resolver contracts: `pkg::Class::method` (namespace wrapping), Erlang `mod::f` (matches remote-call refs), Terraform `var.X` / `local.X` / `module.M` / `data.T.N` / `output.X` / `provider.P[.alias]` and scoped `module.M:file|var.X|output.X|remote-output.X` (only Terraform resolver understands `:`), COBOL `cics-transid:XXXX`, Liquid `snippets/<n>.liquid` / `sections/<n>.liquid`, DFM `${filePath}#${name}`, Svelte/Vue/Liquid `${filePath}::…` forms above, Dart chained encoding `Inner().method`.
- **Marker strings**: return-type marker `'self'` (PHP/Rust); Lombok `decorators:['lombok']` + docstring `Lombok-generated (@X)`; Kotlin decorators `'expect'`/`'actual'`; COBOL section signature `'SECTION'`; VB ctor name `'New'`; Solidity `'constructor'|'fallback'|'receive'`.
- **preParse invariant**: byte-offset preserving (spaces for removed text, newlines kept). Exceptions by design: COBOL free-format shifts columns +7 (lines preserved) and prepends `'CGWIDE '`; VB.NET appends one `\n`.
- **`EXTENSION_MAP`** (full): `.ts .mts .cts`→typescript; `.tsx`→tsx; `.ets`→arkts; `.js .mjs .cjs .xsjs .xsjslib`→javascript; `.jsx`→jsx; `.py .pyw`→python; `.go`; `.rs`→rust; `.java`; `.c .h`→c (`.h` content-sniffed → cpp via `looksLikeCpp` regex incl. `class MACRO Name[:{]` branch, → objc via `/@(?:interface|implementation|protocol|synthesize)\b/`, first 8192 chars); `.cpp .cc .cxx .hpp .hxx .metal .cu .cuh`→cpp; `.cs`→csharp; `.cshtml .razor`→razor; `.php .module .install .theme .inc`→php; `.yml .yaml`→yaml; `.twig`; `.rb .rake`→ruby; `.swift`; `.kt .kts`→kotlin; `.dart`; `.liquid`; `.svelte`; `.vue`; `.astro`; `.r`; `.pas .dpr .dpk .lpr .dfm .fmx`→pascal; `.scala .sc`→scala; `.lua`; `.luau`; `.m .mm`→objc; `.sol`→solidity; `.cfc .cfm`→cfml; `.cfs`→cfscript; `.xml`; `.cbl .cob .cobol .cpy`→cobol; `.vb`→vbnet; `.erl .hrl .escript`→erlang; `.properties`; `.tf .tfvars .tofu`→terraform; `.nix`. Extension-less routes: `conf/routes`/`*.routes`→yaml (Play), `templates|sections/**.json`→liquid (regex `/(^|\/)(templates|sections)\/.+\.json$/i`), `*.app`/`*.app.src`→erlang (`/\.app(?:\.src)?$/i`). File-level-only set: `{yaml, twig, properties}`.
- **Error semantics**: standalone extractors never throw — catch-all pushes `ExtractionError{message, severity:'error', code:'parse_error'}` and returns partial results. Missing grammar → warning error + skip. `EXTRACTION_VERSION = 24` gates re-index recommendations — any port change to output shape implies a bump.

## Rust port notes

- **Crate placement**: everything here → `selene-extract`. `LanguageExtractor` maps cleanly to a Rust trait with default methods (or a config struct + `Option<fn>` hooks); the `*Types` string lists can become `&'static [&'static str]` or precomputed tree-sitter node-type-ID sets (faster than string compares — do the ID lookup once per grammar). `ExtractorContext` becomes a `&mut` extraction session handle. Native tree-sitter crates replace WASM — verify **grammar version parity** for the 15 vendored grammars (Lua ABI-15, C# 0.23.5 primary ctors, patched COBOL, WhatsApp Erlang 0.19, HCL 1.2.0, ArkTS 0.2.0, tree-sitter-nix @3d0173d) or node-type names will drift and every config breaks silently.
- **TS idioms needing redesign**: (1) Erlang's module-level mutable memos (`exportsFile`, `lastFn*`) assume file-sequential single-threaded extraction — make them per-file extractor state in Rust or they break under parallelism. (2) Erlang `handleFunDecl` mutates an already-pushed node's `endLine` through `ctx.nodes` — the context needs mutable access to prior nodes (also ObjC's implementation-merge and Java's Lombok taken-name scan read `ctx.nodes`). (3) Nix relies on tree-sitter cursor `.equals()` semantics (wrapper objects unequal by identity) — Rust `Node` is `Copy`+`PartialEq`, so this hazard disappears but keep the logic. (4) JS regex quirks: `lastIndex` manual rewinds (`re.lastIndex = end` in the balanced-paren blankers), `[-]?` in Liquid regexes (just optional `-`), and multiline `^` anchors — port with `regex` crate carefully; the C++ blanker loops interleave regex matches with manual char scanning over the ORIGINAL string while mutating a char array.
- **Offset math**: all preParse transforms must operate on **bytes** consistently; TS uses UTF-16 string indices, tree-sitter WASM byte offsets — the equal-length-space replacement trick only works if replacement length is measured in the same units the parser sees. In Rust, blank by byte ranges (careful: multi-byte UTF-8 inside macro args — the TS code replaces per-char which preserves char counts, not byte counts; positions survived because tree-sitter-wasm consumed the transformed JS string. In Rust, replace non-ASCII bytes with spaces byte-wise to keep byte offsets exact).
- **Line-number conventions**: tree-sitter rows are 0-based; all emitted lines are `row+1`; Svelte/Vue block offsets are 0-indexed line deltas added to already-1-indexed node lines — a classic off-by-one trap (comments in the code document the exact fix: content starts ON the opening tag's line).
- **Possible bugs/dead code to be aware of (don't “fix” silently — they're contract)**: DFM component `endLine` = start line (no extent tracking); DFM `end` inside quoted strings would pop early (never observed; DFM props are single-line except the skipped forms); Liquid `getLineStart` is O(n²) across matches (re-splits source per call) — fine to optimize, output identical; Svelte template call scan is line-local (multi-line `{expr}` missed — accepted limitation); Svelte `extractTemplateCalls`'s `_scriptBlocks` param is unused (dead); Vue/Svelte covered-range check is line-granular, so a component tag on the same line as `</script>` is skipped; `pascal.ts isExported` always returns false with a comment saying interface-section symbols are exported (handled elsewhere in core); C# `record_struct_declaration` in structTypes is forward-compat dead code (grammar never emits it); Rust `getVisibility` returns `'private'` for `pub(crate)` etc. only checking `.includes('pub')` → actually returns `'public'` for any `pub(...)` — intended.
- **Keep the invariants**: deterministic output ordering (tests assert set-containment mostly, but node IDs embed line numbers — identical input must yield identical IDs); never emit refs for dynamic constructs (CALL data-name, dynamic require/import paths, `this.type`) — “silent beats wrong” is a design rule cited throughout; preParse blanks are curated allowlists — port the exact token lists and regexes above, byte-for-byte.

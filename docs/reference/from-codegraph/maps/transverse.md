## Key algorithms & data flow

**Telemetry.** `SCHEMA_VERSION=2`, `MAX_BUFFER_BYTES=262144`, `MAX_EVENTS_PER_REQUEST=100`, `DEFAULT_FLUSH_TIMEOUT_MS=1500`, `STALE_CLAIM_MS=3_600_000`. State dir default `~/.codegraph` (mkdir mode `0o700`). Consent precedence (first match wins): `DO_NOT_TRACK` truthy (non-empty, ≠'0', ≠'false' case-insensitive) → off; `CODEGRAPH_TELEMETRY` set → on unless '0'/'false'; stored `telemetry.json` → its `enabled`; else default **on**. `recordUsage` aggregates in-memory keyed `[utcDay, kind, name, clientName??'', clientVersion??''].join(' ')`; name truncated to 64 chars, client name 64, version 32. On `process.on('exit')` (single listener for all instances) `persistSync()` appends buffered lines to `telemetry-queue.jsonl`; buffer capped at 256 KB dropping the oldest lines (slice from tail, then drop partial first line). `flushNow`: persist → recover claims older than 1h (append back to queue) → atomically claim queue by `renameSync` to `telemetry-queue.sending.<pid>.jsonl` → parse lines skipping corrupt/wrong-`v` → sendable = all `ev` lines + count lines with `d < today(UTC)`; count lines for today stay queued. Before the first-ever send, `firstRunNotice()` mints `machine_id` (random UUID), writes config `{enabled:true, consent_source:'default-notice', first_run_notice_shown:true}` and prints ONE stderr line: `` codegraph collects anonymous usage stats (no code, paths, or names) — "codegraph telemetry off" or CODEGRAPH_TELEMETRY=0 disables. Details: <TELEMETRY_DOCS>\n ``. Send: chunks of 100 events POSTed as JSON to `env.CODEGRAPH_TELEMETRY_ENDPOINT || 'https://telemetry.getcodegraph.com/v1/events'` with `AbortSignal.timeout(timeoutMs)`; any HTTP response (even 4xx) is final; network failure re-queues remaining chunks. `setEnabled(false)` deletes the queue file. Debug logging gated on `CODEGRAPH_TELEMETRY_DEBUG=1`, prefix `[codegraph telemetry] `. `startInterval` default 6h, `unref`'d. Events: `install`, `index` (props `languages: string[]`, `file_count_bucket`, `duration_bucket`), `uninstall`, plus derived `usage_rollup`. Buckets: files `<100|100-1k|1k-10k|10k+` at 100/1000/10000; duration `<10s|10-60s|1-5m|5m+` at 10_000/60_000/300_000 ms.

**Upgrade detection** (host-independent: path math via target platform's `path.win32|posix`): order matters — (1) normalized filename contains `/_npx/` → `npx`; (2) contains `/node_modules/` → `npm` (`local` if under `resolve(cwd)+'/'` else `global`) — checked BEFORE layout sniffing because the npm thin-installer's per-platform package is itself a bundle (#1071); (3) `bundleRoot = resolve(dirname(filename), '../../..')` has both vendored `node`/`node.exe` and `bin/codegraph`(`.cmd`) → `bundle` (unix installDir = grandparent when parent basename is `versions`; windows when basename lowercased is `current`); (4) `resolve(binDir,'../..')` has `package.json` + `.git` → `source`; else `unknown`. Latest version: GET `https://github.com/<repo>/releases/latest` (UA `codegraph-upgrade`), parse redirect `Location` with `/\/releases\/tag\/([^/?#]+)/` (avoids the 60 req/h API limit, #325); fallback GET `https://api.github.com/repos/<repo>/releases/latest` `.tag_name`. Semver regex `^v?(\d+)\.(\d+)\.(\d+)(?:-([0-9A-Za-z.-]+))?` (not end-anchored — see update-check). Prerelease < release; prerelease strings compared lexically. `runUpgrade`: pin via arg, `--check` reports only; up-to-date short-circuits unless `--force`/pinned. unix bundle → `sh -c "curl -fsSL <install.sh URL> | sh"` (wget fallback) with `CODEGRAPH_INSTALL_DIR`/`CODEGRAPH_VERSION` env; windows bundle → in-place PowerShell `-EncodedCommand` (base64 UTF-16LE) script: download `https://github.com/<repo>/releases/download/<version>/codegraph-win32-<arch>.zip`, rename locked `node.exe` to `node.exe.old-<guid>`, copy over `current\`; npm → `npm install [-g] <pkg>@<spec>` (spec has NO leading `v`), routed through `cmd.exe /d /s /c` on Windows (`.cmd` spawn EINVALs post-CVE-2024-27980); npx/source → informational only. Post-success: probe PATH-resolved `codegraph --version` (last non-empty stdout line) → match/mismatch/inconclusive; self-heal Claude prompt hook (skips on `CODEGRAPH_NO_PROMPT_HOOK=1` or `CODEGRAPH_PROMPT_HOOK=0`); run `codegraph install --refresh` (skip on probe mismatch or `CODEGRAPH_NO_INSTALL_REFRESH=1`).

**Update check.** Disabled when `CODEGRAPH_NO_UPDATE_CHECK` or `DO_NOT_TRACK` truthy. Cache `~/.codegraph/update-check.json` = `{lastAttemptAt, lastSuccessAt?, latest?}`; fresh if success within 24h, else attempt within 1h (failure backoff). Network timeout 5000 ms. **Security rule:** only `canonicalVersionTag()` output (`v{major}.{minor}.{patch}[-pre]` rebuilt from parsed fields) is ever interpolated into the agent-visible notice — never the raw tag (regex isn't end-anchored, so tampered cache could inject text). Failure keeps previous `latest`. Sentinel current version `0.0.0-unknown` → never a notice. Sync reader memoized 60 s per process. Notice string: `` CodeGraph {latest} is available (this server is running {current}). Update with `codegraph upgrade`. ``; stderr line drops leading word: `[CodeGraph] {notice minus 'CodeGraph '}`.

**Binary removal.** Candidate install dirs: detected bundle installDir + `CODEGRAPH_INSTALL_DIR` + platform default (win `%LOCALAPPDATA%\codegraph`, unix `~/.codegraph`). A dir counts only if it has `versions` or `current` artifacts. If dir == state dir (`~/.codegraph`) remove only artifacts (state files survive); else whole dir. Bin shim (`CODEGRAPH_BIN_DIR` or `~/.local/bin/codegraph`, unix only): removed only when its readlink target resolves into a detected install dir or contains `/.codegraph/`. npm global detected via `npm root -g` + package dir existence. Executor: refuses filesystem roots; on rm failure on win32 renames the running `node.exe` to `codegraph-old-node-<pid>.exe` beside the dir, retries, reports leftovers; source checkouts reported never deleted.

**project-config `codegraph.json`.** mtime-cached per root (`Map<root,{mtimeMs,config}>`); missing/bad JSON/bad field → zero-config default with `logWarn` (message strings are part of UX: e.g. ``Ignoring codegraph.json: not valid JSON``). Extension key normalization: trim+lowercase, ensure leading `.`, reject empty/multi-dot (`.d.ts`)/path separators; value must pass `isLanguageSupported`. User mappings merge OVER built-ins. Pattern fields (`includeIgnored`, `exclude`, `include`): arrays of trimmed non-empty gitignore-style strings, invalid entries warned-and-skipped. `addIncludeIgnoredPatterns`: read-modify-write plain JSON (throws `` codegraph.json is not valid JSON — fix it by hand, then re-run. `` on unparseable existing file), dedup-append, writes `JSON.stringify(config, null, 2)+'\n'`, returns added count.

**directory.ts.** `CODEGRAPH_DIR` env override must be a plain segment (rejects empty, `.`, contains `..`, `/`, `\\`, absolute → warn once to stderr, keep `.codegraph`). `isCodeGraphDataDir` matches `.codegraph`, active override, and any `.codegraph-*`. `isInitialized` = dir exists AND `<dir>/codegraph.db` exists. `unsafeIndexRootReason`: realpath-resolve; filesystem root (`path.parse(p).root === p`) → `'the filesystem root'`; == home (case-insensitive on darwin/win32) → `'your home directory'`; ancestor of home → `'a parent of your home directory'`; else null (overridable with `--force` in CLI). `findIndexedSubprojectRoots`: BFS, maxDepth 4, max 64, skips dot-dirs and `SUBPROJECT_SCAN_SKIP` = {node_modules, .git, .svn, .hg, dist, build, out, target, vendor, bin, obj, .next, .nuxt, .svelte-kit, .cache, coverage, .venv, venv, __pycache__, .turbo, .idea, .vscode, tmp, temp}; stops descending at an indexed dir. `planFrontload`: (1) up-walk ≤6 levels for an indexed ancestor; (2) down-scan only if cwd has one of `WORKSPACE_ROOT_MANIFESTS` = [package.json, pnpm-workspace.yaml, lerna.json, nx.json, turbo.json, go.work, go.mod, Cargo.toml, pom.xml, build.gradle, build.gradle.kts, settings.gradle, pyproject.toml, composer.json, Gemfile, rush.json, WORKSPACE, WORKSPACE.bazel]; multiple subs → score 10 for prompt containing rel path (lowercased, `/`-normalized), 5 for `\b<basename>\b` (name len ≥3), tie-break shorter rel path; no match → `exploreRoot:null` + full nudge list. Prompt gate: Unicode-aware boundaries `(?<![\p{L}\p{N}_])` / `(?![\p{L}\p{N}_])` (JS `\b` is ASCII-only, #994/#1126); three matcher classes — `STRUCTURAL_WORDS` (exact words, ~29 languages), `STRUCTURAL_STEMS` (left-boundary prefixes; English `call/trace/affect/connect` carry enumerated suffix sets + right boundary, #1138), `STRUCTURAL_UNSEGMENTED` (bare substrings for CJK/Thai/Korean/Arabic/Farsi/Hebrew) — port these regexes verbatim. `extractCodeTokens`: identifier runs `/[A-Za-z_$][\w$]*/g` kept when `/[a-z][A-Z]/` or `/[A-Za-z0-9]_[A-Za-z0-9]/`; call form `([A-Za-z_$][\w$]*)\(` (no space before paren); member access `a.b` unless whole match ends with `DOC_DATA_EXT` = `\.(md|markdown|txt|rst|json|ya?ml|toml|lock|csv|tsv|log|ini|cfg|conf|env|xml|html?|png|jpe?g|gif|svg|pdf)$/i`. `.codegraph/.gitignore` content is exact (header `# CodeGraph data files`, wildcard `*` + `!.gitignore`); `isStaleDefaultGitignore` = has header but no bare `*` line → regenerate; user-authored files untouched. `removeDirectory` unlinks a symlinked `.codegraph` instead of following it; `listDirectoryContents`/`getDirectorySize` skip symlinks; `ensureSubdirectory` rejects names containing `..` or separators.

**utils security.** `SENSITIVE_PATHS` (exact set, checked as-is AND lowercased): `/`, `/etc`, `/usr`, `/bin`, `/sbin`, `/var`, `/tmp`, `/dev`, `/proc`, `/sys`, `/root`, `/boot`, `/lib`, `/lib64`, `/opt`, `c:\`, `c:\windows`, `c:\windows\system32`. `validateProjectPath` additionally refuses `~/.ssh`, `~/.gnupg`, `~/.aws`, `~/.config` (and anything under them), then requires an existing directory; returns an error STRING (`Refusing to operate on sensitive system directory: <p>` / `Refusing to operate on sensitive directory: <p>` / `Path is not a directory: <p>` / `Path does not exist or is not accessible: <p>`) or null — MCP wraps non-null in `PathRefusalError` (the only `isError:true` class). `validatePathWithinRoot`: (1) lexical containment of `resolve(root, fp)` in `resolve(root)` (case-insensitive compare on win32); (2) realpath both sides, re-check containment (rejects symlink escapes, #527); `allowSymlinkEscape:true` waives ONLY step 2 (indexing read path, #935); ENOENT during realpath → allow lexical path; any other errno (ELOOP, EACCES) → reject. `FileLock`: lock file contains the PID as text; stale if mtime age ≥ `STALE_TIMEOUT_MS = 120_000` OR pid dead (`process.kill(pid,0)` throws); acquire writes with flag `'wx'`, EEXIST race → throw; error message includes `` run 'codegraph unlock' or delete <lockPath> ``; release only if file still holds own PID.

**UI.** `supportsUnicode()`: `CODEGRAPH_ASCII=1`→false; `CODEGRAPH_UNICODE=1`→true; win32→false; `TERM==='linux'`→false; else true. Glyph sets in inventory above (Unicode spinner `['·','✢','✳','✶','✻','✽']`, ASCII `['.','*','+','x','o','O']`; both 6 frames — count parity is tested). Shimmer worker: renders every 50 ms; `ANIM_INTERVAL=150` ms per animation frame, `FRAMES_PER_GLYPH=3`; shimmer color sinusoid period 13 frames lerping RGB (160,100,9)→(251,191,36) with bold; bar width 25, shimmer sweep window 3 cells cycling over 24 frames; writes `\r\x1b[K<line>` via `fs.writeSync(1,…)` (bypasses the main-thread-proxied stdout so animation survives SQLite blocking). Phase names: scanning→`Scanning files`, parsing→`Parsing code`, storing→`Storing data`, resolving→`Resolving refs`. `finish-phase` prints `│  ◆ <msg> — done` (green diamond) or `— N found`. `stop()` waits ≤2000 ms for `{type:'stopped'}` then force-terminates.

**Facade `indexAll` orchestration order** (port faithfully): mutex → file lock → WAL-defer valve (skip if `CODEGRAPH_NO_WAL_DEFER=1` or journal ≠ wal; set autocheckpoint 0, restore after) → metadata `index_state='indexing'` → clear segment vocab → orchestrator.indexAll → fold WAL → resolver re-`initialize()` + `runPostExtract()` → batched resolution → `resolveChainedCallsViaConformance()` → `resolveDeferredThisMemberRefs()` → `runMaintenance()` → recompute node/edge deltas from DB → stamp `indexed_with_version` + `indexed_with_extraction_version` → reconcile: `discovered - (indexed+skipped+errored) > 0` ⇒ `index_state='partial'` + warning code `index_partial`, else `'complete'`; failure ⇒ `'failed'`. `sync()` adds: git-scoped ref resolution, `#1240` failed-ref retry, `#1187` orphan sweep (`getUnresolvedReferencesCount()>0` → batched pass), segment-vocab backfill when vocab was empty at start (batch 2000, yielding). `getSegmentMatches`: tier A co-occurrence (≥2 distinct prompt words on one name), tier B single rare word only if tier A empty (word length ≥5, segment in 2..`SEGMENT_RARITY_CEILING=25` names, candidate has ≥2 segments); every candidate re-verified against live nodes, representative must not be kind `file`/`import`.

## Wire/contract surfaces

- **`.codegraph/` (per-project; name overridable via `CODEGRAPH_DIR`):** `codegraph.db` (SQLite, presence = "initialized") + `-wal`/`-shm` sidecars; `codegraph.lock` (FileLock, PID text); `daemon.pid` (JSON pid+socket+version record, mcp subsystem); `daemon.sock` (unix socket / named pipe; falls back to tmpdir when path too long); `daemon.log`; `.gitignore` (exact bytes: header comment + `*` + `!.gitignore`). There is **no** `.codegraph/config.json` — project config is the committed root-level `codegraph.json`.
- **`~/.codegraph/` (global state):** `telemetry.json` `{enabled, machine_id, consent_source: 'installer'|'default-notice'|'cli', first_run_notice_shown?, updated_at}` (pretty-printed, trailing newline); `telemetry-queue.jsonl` (lines: count `{v,d,k,n,c,e,cn?,cv?}` or event `{v,ev,ts,props}`); `telemetry-queue.sending.<pid>.jsonl` claims; `update-check.json` `{lastAttemptAt, lastSuccessAt?, latest?}`; `daemons/` registry; on unix also bundle artifacts `versions/` + `current` symlink.
- **Telemetry POST body:** `{machine_id, codegraph_version, os, arch, node_major, ci, schema_version: 2, events: [{event, ts, props}]}`; count lines become `event:'usage_rollup'` with `ts: '<day>T12:00:00.000Z'`, props `{kind, name, count, error_count, client_name?, client_version?}`. Header `content-type: application/json`. Allowlist enforced server-side (`telemetry-worker/`); TELEMETRY.md is the user contract (no code/paths/names/IPs; machine id = random UUID; schema bump requires doc update).
- **Env vars (all part of the contract):** `DO_NOT_TRACK`, `CODEGRAPH_TELEMETRY`, `CODEGRAPH_TELEMETRY_ENDPOINT`, `CODEGRAPH_TELEMETRY_DEBUG`, `CODEGRAPH_NO_UPDATE_CHECK`, `CODEGRAPH_DIR`, `CODEGRAPH_INSTALL_DIR`, `CODEGRAPH_BIN_DIR`, `CODEGRAPH_VERSION`, `CODEGRAPH_NO_INSTALL_REFRESH`, `CODEGRAPH_NO_PROMPT_HOOK`, `CODEGRAPH_PROMPT_HOOK`, `CODEGRAPH_ASCII`, `CODEGRAPH_UNICODE`, `CODEGRAPH_DEBUG`, `CODEGRAPH_NO_WAL_DEFER`, `CODEGRAPH_SYNTH_TIMINGS`.
- **Error semantics:** library errors carry `.code` strings (`FILE_ERROR`, `PARSE_ERROR`, `DATABASE_ERROR`, `SEARCH_ERROR`, `VECTOR_ERROR`, `CONFIG_ERROR`). MCP layer: only `PathRefusalError` (from `validateProjectPath` non-null) and genuine malfunctions → `isError:true`; `NotIndexedError` and all recoverables → success-shaped text.
- **package.json:** name `@colbymchenry/codegraph`, version `1.4.1`, `bin: {codegraph: ./dist/bin/codegraph.js}`, `main: dist/index.js`, `preuninstall: node dist/bin/uninstall.js` (config cleanup when npm removes the package), engines `>=20.0.0 <25.0.0` (hard exit in `src/bin/node-version-check.ts`), `files: [dist, scripts, README.md]`. Release artifacts: GitHub release zips `codegraph-<platform>-<arch>` and npm thin-installer shim + per-platform packages.

## Rust port notes

- **Crate placement:** telemetry + update-check + upgrade/remove-binary → `selene-cli` (or a small `selene-cli/src/telemetry.rs` etc.; nothing else consumes them). `project-config`, `directory` (dir mgmt + unsafe-root), `errors`, path-security from `utils` → `selene-core` (consumed by extract/db/mcp/cli alike). Front-load prompt-gate half of `directory.ts` (keywords/tokens/planFrontload) is really MCP-hook logic → `selene-mcp`. UI shimmer → `selene-cli` (a render thread replaces the worker; Rust has no main-thread-blocked-stdout problem, but keep direct-fd writes if the indexer blocks). `FileLock` → `selene-db` (guards the store); `Mutex`/`processInBatches`/debounce/throttle/MemoryMonitor are JS idioms — use `tokio::sync::Mutex`, rayon/stream chunks, drop `estimateSize`/`MemoryMonitor` unless needed. The `CodeGraph` facade maps onto the whole selene workspace: its method list is effectively the `GraphStore`+graph+context API inventory — decide against PRD §5.4 before freezing.
- **Regex port pitfalls:** the structural-keyword regexes rely on Unicode property lookbehind `(?<![\p{L}\p{N}_])` — `regex` crate has no lookaround; use `fancy-regex` or restructure as "find match, check flanking chars manually". Port `STRUCTURAL_WORDS`/`STEMS`/`UNSEGMENTED` lists byte-for-byte (case-insensitive + Unicode flags); note entries are themselves regex fragments (`flows?`, `percors[oi]`, bounded English stems).
- **Env truthiness is inconsistent by design:** DNT/`CODEGRAPH_TELEMETRY` use non-empty-≠'0'-≠'false'; kill switches like `CODEGRAPH_NO_WAL_DEFER`/`CODEGRAPH_ASCII` compare `=== '1'` exactly; `CODEGRAPH_PROMPT_HOOK === '0'`. Replicate exactly.
- **Exit-time persist:** Node's `process.on('exit')` sync write → in Rust prefer explicit flush on drop plus a best-effort atexit; there is no equivalent of "fires under process.exit()" — panics/`std::process::exit` will skip Drop, so persist eagerly (e.g. after each record beyond a small delay) or accept the loss (telemetry is best-effort).
- **Case-insensitive path compares** on darwin+win32 (`unsafeIndexRootReason`) but only win32 in `isWithinDir` — keep that asymmetry (it's deliberate: macOS FS is case-insensitive for home comparison, but realpath output on macOS preserves case consistently for containment).
- **`FileLock` stale detection** uses `process.kill(pid, 0)` — use `kill(pid,0)` via nix on unix, `OpenProcess` on Windows; note the CI caveat from CLAUDE.md: without a reaping PID 1, zombies report alive.
- **Suspicious/dead TS to not blindly port:** `VectorError` is unused legacy (no vector ops remain); `CodeGraph.destroy()` deprecated alias; `estimateSize`/`readFileInChunks` appear unused; `directory.ts`'s `CODEGRAPH_DIR` const doc admits it's a backward-compat snapshot — expose only the function in Rust. In `upgrade.ts` `deriveInstallDir` unix branch returns `P.dirname(parent)` in both arms of the `exists` ternary (`exists(installDir) ? installDir : P.dirname(parent)` where `installDir = P.dirname(parent)`) — the probe is a no-op; simplify. `telemetry.packageVersion()` reads `__dirname/../../package.json` — in Rust bake `env!("CARGO_PKG_VERSION")`.
- **Windows self-update dance** (rename locked exe, cmd.exe routing for `.cmd`, `-EncodedCommand` UTF-16LE) is Node/npm-specific; a single static Rust binary can replace it with the standard rename-self + copy-new pattern (`self_replace` crate) — keep the *behavioral* contract (in-place, no detached helper, version probe afterwards).
- **Keep both budgets/limits tables and every constant above literal** — bucket edges, TTLs (24h/1h/5s/12s), 256 KB cap, 100-event chunks, 1500 ms flush, 2-min lock staleness, scan bounds (depth 4/max 64/up-walk 6), rarity ceiling 25, shimmer timing (50/150/3/13/24/25/3) — these are the compatibility surface with existing `.codegraph`/`~/.codegraph` state and user expectations.

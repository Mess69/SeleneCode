## Key algorithms & data flow

**1. File enumeration (`scanDirectory`).** Git fast path: `git rev-parse --show-toplevel`; if root ≠ toplevel and `git check-ignore -q <root>` exits 0 → filesystem walk fallback. Otherwise `collectGitFiles`: `git ls-files -z -s --recurse-submodules` (mode-160000 gitlink entries collected separately and recursed as embedded repos if a real `.git` checkout exists), plus `git ls-files -z -o --exclude-standard` for untracked; a trailing-slash untracked dir with a `.git` **directory** is an embedded repo (recurse); a `.git` **file** whose `gitdir:` matches `/(^|[\\/])\.git[\\/](modules[\\/][^\\/]+[\\/])?worktrees[\\/]/` is a worktree → skip. Gitignored embedded repos are discovered only when opted-in via `codegraph.json` `includeIgnored`. Result filtered through `ScopeIgnore` (defaults + root `.gitignore`; per-embedded-repo matchers, longest-root-first; user `exclude` wins over everything; user `include` forces files back in unless default-ignored). Non-git fallback: recursive walk with per-directory scoped `.gitignore` matchers, symlink-cycle guard via `realpathSync` visited set. Default ignore dirs (`DEFAULT_IGNORE_DIRS`, 60+ names: `node_modules`, `dist`, `build`, `out`, `.output`, `target`, `vendor`, `__pycache__`, `.venv`, `venv`, `coverage`, `.next`, `.gradle`, `obj`, `Pods`, `.dart_tool`, `__history`, `.cache`, …) plus globs `*.egg-info/`, `cmake-build-*/`, `bazel-*/`, `**/res/<androidType>*/` for 12 Android res types. Defensive `.gitignore` reader: reject NUL/invalid-UTF-8 files whole; per-line compile-probe (`ignore().add(line).ignores('.codegraph-probe')`) drops only uncompilable lines. Constants: `EMBEDDED_REPO_SEARCH_DEPTH=4`, `EMBEDDED_REPO_SEARCH_ENTRIES=2000`, `UNINDEXED_IGNORED_REPO_HINT_CAP=100`, git exec timeouts 5s/10s/30s, `maxBuffer` 50 MB.

**2. indexAll pipeline.** `initGrammars()` → scan → framework detection once per run (`detectFrameworks` over a filesystem-backed `ResolutionContext`; names threaded to every parse) → needed languages = set of `detectLanguage(file)` (+`cpp` whenever `c` present) → grammar WASM bytes pre-read once (`readGrammarWasmBytes`) → `ParseWorkerPool` (size = `CODEGRAPH_PARSE_WORKERS` or `clamp(cores-1,1,8)`, hard max 16) or in-process fallback when `parse-worker.js` missing. Reads happen in batches of `FILE_IO_BATCH_SIZE=10`; each readable file ≤ `MAX_FILE_SIZE=1 MiB` (larger ⇒ warning `size_exceeded`, counted skipped) is dispatched into a **bounded rolling window** `windowSize = max(4, poolSize*2)`; results are buffered by dispatch sequence number and **committed to SQLite strictly in original file order** (determinism: resolution disambiguates same-named symbols by insertion order). Commits are serialized on a promise chain; `STORE_CHUNK=2000` rows per sub-transaction with a cooperative yield between chunks; optional WAL backpressure hook awaited between files. Retry pass for errors whose message contains `'Worker exited'`, `'memory access out of bounds'`, or `'timed out'`: `pool.recycleAll()` then one-at-a-time re-parse; still-failing files retried once more with comment-only lines (`/^\s*\/\//`) blanked to `''` (line numbers preserved). Success = `filesIndexed > 0 || no severity:'error'`.

**3. Store (`storeExtractionResult`) — the DB contract.** (a) `contentHash = sha256(content)`; if existing file record has same hash → no-op. (b) Snapshot incoming cross-file edges (`getCrossFileIncomingEdgesWithTarget`) **before** `deleteFile` (cascade kills them). (c) `deleteFile(path)`. (d) `validNodes` = nodes with all of `id,kind,name,filePath,language`; insert chunked. (e) Same-file edges filtered to `source∈insertedIds && target∈insertedIds` (cross-file linking is exclusively the resolver's job via unresolved refs). (f) Re-insert snapshot edges re-targeted by lookup key `` `${kind}\0${name}` `` against the new nodes (ids embed the line, so line shifts change every id — issue #899); an edge whose target vanished is resurrected as its original `UnresolvedReference` from `edge.metadata.refName/refKind` stamps (no stamp ⇒ drop silently). (g) Unresolved refs filtered to `fromNodeId∈insertedIds`, denormalized with `filePath`/`language`, chunk-inserted. (h) `upsertFile(FileRecord)` **last** — a crash mid-store leaves no file record, so the file re-indexes.

**4. Incremental sync.** `sync()` is filesystem-based, never git: enumerate current files; removals = tracked-in-DB but not in set **or** `!existsSync` (resurrect incoming edges as refs first, then `deleteFile`); adds/mods pre-filtered by `stat.size === tracked.size && Math.floor(stat.mtimeMs) === Math.floor(tracked.modifiedAt)` (skip), else read+`hashContent` compare; changed files re-indexed one-by-one via `indexFile`. Cooperative yield (`setImmediate`) every `SYNC_RECONCILE_YIELD_INTERVAL=1000` reconcile checks. `getChangedFiles()` (status reporting only) uses `git status --porcelain --no-renames` per repo recursively; `??`+dir ⇒ embedded-repo recursion; `D` reported only if tracked in DB; `??`/`M` read+hash-compared against DB (untracked-but-indexed files stay "unchanged", #206).

**5. Worker protocol (`parse-worker.ts`/`parse-pool.ts`).** Messages: main→worker `{type:'load-grammars', languages, grammarBuffers?}` ⇒ worker `{type:'grammars-loaded'}`; main→worker `{type:'parse', id, filePath, content, frameworkNames, language}` ⇒ `{type:'parse-result', id, result, parseMs}`; `{type:'shutdown'}`⇒`{type:'shutdown-ack'}`. Worker calls `extractFromSource`; every `PARSER_RESET_INTERVAL=5000` parses per language it `resetParser`s; on error containing `memory access out of bounds`/`out of memory` it `process.exit(1)` (pool respawns). Pool policy: per-parse budget = `parseTimeoutMs (default 10_000, env CODEGRAPH_PARSE_TIMEOUT_MS) + floor(contentLen/100_000)*10_000`; base timer only **marks late** (late results accepted); hard kill at `HARD_KILL_MULTIPLIER=3`× budget; recycle worker after `WORKER_RECYCLE_INTERVAL=250` parses (WASM heap never shrinks); `MAX_CONCURRENT_SPAWN=2` cold starts; `CRASH_BUDGET=100` total deaths then fail outstanding work. Worker stderr write is monkey-patched to swallow lines starting `Aborted(` or containing `Build with -sASSERTIONS for more info`.

**6. Grammar/loading (`grammars.ts`).** `initGrammars()` = `Parser.init()` once. `loadGrammarsForLanguages` expands SFC deps (svelte/vue/astro ⇒ +typescript,+javascript; cfml ⇒ +cfscript,+cfquery), loads WASMs **sequentially** (web-tree-sitter race, tree-sitter#2338); a failed load is memoized in `unavailableGrammarErrors` and warned once. 15 vendored grammars ship in `wasm/` (`pascal, scala, lua, luau, csharp, r, cfml, cfscript, cfquery, cobol, vbnet, erlang, terraform, arkts, nix`); the rest resolve from the `tree-sitter-wasms` npm package. `getParser` caches one `Parser` per language. `detectLanguage`: special-cases first (`conf/routes`→`yaml`, `templates|sections/**/*.json`→`liquid` via `/(^|\/)(templates|sections)\/.+\.json$/i`, `/\.app(?:\.src)?$/i`→`erlang`), then overrides map, then `EXTENSION_MAP` (lowercased last-dot extension), else `unknown`; a `.h` detected `c` is sniffed on first 8192 chars — C++ regex `\bnamespace\b|\bclass\s+\w+\s*[:{]|\b(?:class|struct)\s+[A-Z][A-Z0-9_]+\s+\w+\s*(?:final\s*)?[:{]|\btemplate\s*<|\b(?:public|private|protected)\s*:|\bvirtual\b|\busing\s+(?:namespace\b|\w+\s*=)`, ObjC regex `@(?:interface|implementation|protocol|synthesize)\b`. File-level-only languages (no symbols, still indexed): `yaml`, `twig`, `properties`.

**7. `extractFromSource` dispatch.** svelte/vue/astro/liquid/razor → their standalone extractor; `xml` → `MyBatisExtractor`; `cfml`/`cfscript` → `CfmlExtractor`; file-level-only → empty result; pascal + `.dfm|.fmx` → `DfmExtractor`; else `TreeSitterExtractor`. Then framework extractors (`fw.extract(filePath, source)`) matching detected framework names + language append `nodes`/`references` (failures → warning error, never fatal).

**8. TreeSitterExtractor walk.** Emits a **file node** `{ id: "file:" + filePath, kind:'file', name: basename, qualifiedName: filePath, startLine:1, endLine: source.split('\n').length }`, pushes it on `nodeStack`, optionally creates a `namespace` node from a package header (Java/Kotlin/Erlang via `packageTypes`/`extractPackage`), then `visitNode(root)`. `visitNode` dispatch ladder (first match wins; most branches set skipChildren because sub-extractors walk their own bodies): custom `extractor.visitNode` hook → pascal special → C++ `namespace_definition` (pushes `namespacePrefix`, no node minted) → fnRef capture → functionTypes (inside class-like + also in methodTypes ⇒ method) → classTypes (via `classifyClassNode` → class/struct/enum/interface/trait) → extraClassNodeTypes → methodTypes (`classifyMethodNode` may demote to property, #808) → interfaceTypes → structTypes → enumTypes → typeAliasTypes → propertyTypes/fieldTypes (inside class) → variableTypes (top-level only, or Ruby class-scope `CONST=`) → swift property special-case → TS/JS re-export & Vue-store export branches → callTypes → `INSTANTIATION_KINDS` = `{new_expression, object_creation_expression, instance_creation_expression, composite_literal, struct_expression, instance_expression}` (+ anonymous-class body extraction) → `impl_item` (Rust `implements` ref) → TS interface member signatures (type refs). Function bodies are walked by a second walker `visitFunctionBody` which extracts calls, instantiations, bare calls (`extractBareCall`), static member reads (`MEMBER_ACCESS_TYPES` receivers, gated to `STATIC_MEMBER_LANGS = {java,csharp,kotlin,swift,scala,dart,php,cpp}`), local var type annotations, nested **named** functions, and nested structural types. `<anonymous>` functions get no node but their body is still walked (module wrappers, #528). Misparsed functions (`isMisparsedFunction`) likewise skip the node but walk the body.

**9. Node id + qualified name (EXACT).**
```
generateNodeId(filePath, kind, name, line /* 1-based startLine */)
  = `${kind}:` + hex(sha256(`${filePath}:${kind}:${name}:${line}`)).substring(0, 32)
```
Exception: the file node id is the **unhashed** literal `file:<filePath>`. (The doc comment in `types.ts` claiming "hash of file path + qualified name" is stale — the input is `path:kind:name:startLine`.) `qualifiedName = [...namespacePrefix(C++ only), ...names of non-file nodes on nodeStack, name].join('::')` — no file path component (FTS pollution). Overrides: receiver methods get `qualifiedName = ` `` `${receiverType}::${name}` `` (Go/Rust/Lua); TS type-alias members get `` `${TypeAlias}::${member}` ``. `createNode` skips empty names (returns null), extends `endLine` to a sibling-resolved body (Dart/Pascal), pushes a `contains` edge from the stack top, merges `extractModifiers` into `decorators`.

**10. Call extraction (generic path).** Callee name for `call_expression`-likes: member receivers (`member_expression|attribute|selector_expression|navigation_expression|field_expression`) yield `receiver.method` when receiver is a simple identifier not in `{self,this,cls,super}` (VB.NET also skips `me,mybase,myclass` case-insensitively), else bare `method`; call-receivers in c/cpp/kotlin/swift/rust/go/scala/csharp re-encode chained factories as `` `${innerCallee}().${method}` `` (marker `().` is a resolver contract; Rust only when inner is `scoped_identifier`, Go only bare `identifier`, Kotlin/Swift/Scala only capitalized inner); `scoped_identifier` calls keep full `Module::function` text; Go conversions `(*T)(x)` normalize via `/^\(\s*\*?\s*([A-Za-z_][\w.]*)\s*\)$/`; C/C++ template args stripped. Result pushed as `UnresolvedReference{referenceKind:'calls', line, column}` — **extraction never resolves cross-file; it emits refs and the resolver makes edges**. Value-reference pass (`flushValueRefs`, default on, `CODEGRAPH_VALUE_REFS=0` disables): same-file `references` edges (metadata `{valueRef:true}`) from function/method/const/var scopes to file/class-scope constants with `name.length>=3 && /[A-Z_]/`, shadow-pruned by counting declarators vs file-scope defs, capped at `MAX_VALUE_REF_NODES=20_000` visits. Function-as-value pass (`flushFnRefCandidates`): candidates gated to same-file function/method names ∪ import bindings (regexes `^[A-Za-z_$][A-Za-z0-9_$]*$` and `^[A-Za-z_$][A-Za-z0-9_$.\\]*[.\\]([A-Za-z_$][A-Za-z0-9_$]*)$`), emitted as `referenceKind:'function_ref'`; skipped entirely for `isGeneratedFile` paths.

**11. The three deep-dive extractor configs.**
- **typescript** (`typescript.ts`, shared by `tsx`): functionTypes `[function_declaration, arrow_function, function_expression]`; classTypes `[class_declaration, abstract_class_declaration]`; methodTypes `[method_definition, public_field_definition]` with `classifyTsClassMember` (field is a method only if value is arrow/function-expression or a call wrapping one — else property); interfaces `[interface_declaration]`; enums `[enum_declaration]` (members `property_identifier, enum_assignment`); typeAlias `[type_alias_declaration]`; imports `[import_statement]`; calls `[call_expression]`; variables `[lexical_declaration, variable_declaration]`; name/body/params fields `name/body/parameters`, return `return_type`. `resolveBody` digs arrow bodies out of field definitions and HOF wrappers. `isExported` walks ancestors for `export_statement`; `isConst` true only for `lexical_declaration` with a `const` child; signature = params text + `: returnType`. Core adds TS-specific machinery: arrow-const naming from `variable_declarator`, React HOC components (`forwardRef|memo|React.*|/^styled\b/` + PascalCase ⇒ `component` node), exported object-of-functions / Zustand `create(...)` / RTK `createApi` endpoints (`RTK_HOOK_NAME_RE = /^use[A-Z][A-Za-z0-9]*(?:Query|Mutation)$/`) / Pinia/Vuex store collections (`{actions,mutations,getters}` × `{defineStore,createStore}`, ≥2 hits of `VUE_STORE_FILE_SIGNAL`), import-binding refs, re-export refs, type-annotation `references` (TS ∈ `TYPE_ANNOTATION_LANGUAGES = {typescript,tsx,arkts,dart,kotlin,swift,rust,go,java,csharp,scala,php}`; `BUILTIN_TYPES` filtered).
- **python**: functionTypes=methodTypes=`[function_definition]` (method iff inside class-like); classTypes `[class_definition]`; imports `[import_statement, import_from_statement]`; calls `[call]`; variables `[assignment]`; signature = params + `" -> "` + return; `isAsync` = previous sibling `async`; `isStatic` = preceding `decorator` containing `staticmethod`. `extractImport` handles only `import_from_statement` (module name); core handles `import a, b` inline (one `import` node + `imports` ref per dotted_name/aliased_import) and `emitPyFromImportRefs` for `from m import X` per-name refs.
- **rust**: functionTypes=methodTypes=`[function_item, function_signature_item]` (trait method decls are first-class); classTypes `[]`; interfaces `[trait_item]` with `interfaceKind:'trait'`; structs `[struct_item]`; enums `[enum_item]` (members `enum_variant`); typeAlias `[type_item]`; imports `[use_declaration]`; calls `[call_expression]`; variables `[let_declaration, const_item, static_item]`. `getReceiverType` climbs to `impl_item` and takes the **last** direct `type_identifier` (handles `impl Trait for Type`, generic `impl<T> S<T>` via `generic_type`) — presence flips function→method, sets `qualifiedName = Type::name`, and the core links a same-file `contains` edge from the struct/enum/trait node found by name. `getReturnType` normalizes `-> &Foo`/`Vec<Foo>`/`a::b::Foo` to bare last segment; `-> Self` ⇒ marker string `'self'`; primitives/unit/tuple ⇒ undefined. `getVisibility` defaults `'private'`, `pub` ⇒ `'public'`. `extractImport` returns the **root** crate/module segment of the use path; core's `emitRustUseBindingRefs` adds per-leaf refs; `impl_item` in visitNode emits `implements` refs.

## Wire/contract surfaces

- **Node id format** (above) — DB primary key, edge endpoints, and the resolver all depend on it. `file:<relpath>` prefix and `<kind>:<32-hex>` prefixes are used as scope discriminators elsewhere (`parentId.startsWith('file:')`, `'class:'`, `'struct:'`, `'module:'`, `'enum:'`) — so the `kind:` prefix is load-bearing, not cosmetic.
- **NodeKind (22) / EdgeKind (12) strings** from `src/types.ts` — already mirrored in `selene-core`; `ReferenceKind = EdgeKind | 'function_ref'` (`function_ref` never persists as an edge kind; resolution maps it to `references`).
- **Node shape**: `{id, kind, name, qualifiedName, filePath, language, startLine(1-based), endLine, startColumn(0-based), endColumn, docstring?, signature?, visibility?('public'|'private'|'protected'|'internal'), isExported?, isAsync?, isStatic?, isAbstract?, decorators?[], typeParameters?[], returnType?, updatedAt(ms)}`. Edge: `{source, target, kind, metadata?, line?, column?, provenance?('tree-sitter'|'scip'|'heuristic')}`. `UnresolvedReference: {fromNodeId, referenceName, referenceKind, line, column, filePath?, language?, candidates?}`. `FileRecord: {path, contentHash(sha256 hex), language, size, modifiedAt(mtimeMs), indexedAt, nodeCount, errors?}`.
- **Chained-call marker** `` `inner().method` `` and qualified-name separator `::` (`mod::fn` for Erlang remote calls, `Receiver::method`, C++ `ns::fn`) are extractor↔resolver contracts.
- **Edge metadata stamps**: `refName`/`refKind` (written by resolution's `createEdges`, read by `resurrectRefFromDroppedEdge`), `valueRef: true`, `synthesizedBy`/`registeredAt` on heuristic edges.
- **Error codes** on `ExtractionError`: `unsupported_language`, `parser_error`, `parse_error`, `read_error`, `path_traversal`, `size_exceeded`; severity `'error'|'warning'`. Retry-pass matching is **string-based on messages**: `'Worker exited'`, `'memory access out of bounds'`, `'timed out'`.
- **Env vars**: `CODEGRAPH_PARSE_WORKERS`, `CODEGRAPH_PARSE_TIMEOUT_MS`, `CODEGRAPH_VALUE_REFS=0`, `CODEGRAPH_SYNTH_TIMINGS` (stderr `[phase-timing] …`), `CODEGRAPH_WASM_RELAUNCHED`, `CODEGRAPH_NO_RELAUNCH`, `CODEGRAPH_HOST_PPID`.
- **`EXTRACTION_VERSION = 24`** — persisted with the index; running-engine > on-disk ⇒ "re-index recommended".
- **Docstring cleanup** output (markers stripped per `cleanCommentMarkers`, comments joined with `\n`, trimmed) is user-visible in MCP output.
- `EXTENSION_MAP` is the single source of truth for indexability; drifting it changes which files are counted/indexed.

## Rust port notes

- **Crate placement**: scanning/ignore/embedded-repo logic + orchestrator → `selene-extract` (scan may split into `selene-sync` for `sync()`/`getChangedFiles`); `extractFromSource`, `TreeSitterExtractor`, `LanguageExtractor` trait, helpers, grammars → `selene-extract`; `generateNodeId`, `ExtractionResult`-adjacent types → `selene-core`; DB handoff via the `GraphStore` trait in `selene-db`. `EXTRACTION_VERSION` → `selene-core`.
- **WASM layer disappears**: use native `tree-sitter` crates (statically linked grammars). This deletes the entire raison d'être of: worker recycling (`WORKER_RECYCLE_INTERVAL`, `PARSER_RESET_INTERVAL`), WASM-OOM crash/retry/comment-strip passes, `wasm-runtime-flags.ts`, the stderr `Aborted(` filter, grammar-bytes pre-read, and sequential grammar loading. Keep: per-parse timeout as a safety net, `MAX_FILE_SIZE`, the retry concept only if native parsing proves fallible (it mostly isn't). Replace worker_threads with rayon/thread-pool; the **ordered-commit invariant** (file-order determinism for resolution tie-breaking, #1015) must be preserved.
- **Node.id determinism**: reproduce `sha256` over the exact template `"{filePath}:{kind}:{name}:{line}"`, hex, truncate to 32 chars, prefix `"{kind}:"`; file nodes are literal `file:{path}` — and code elsewhere key-matches on id **prefixes**, so keep them.

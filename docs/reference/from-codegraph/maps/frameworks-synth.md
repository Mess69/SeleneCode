## Public interface

```ts
// resolution/types.ts
interface FrameworkResolver {
  name: string;
  languages?: Language[];                       // omit = applies to all languages
  detect(context: ResolutionContext): boolean;  // project-level, once at resolver init
  resolve(ref: UnresolvedRef, context: ResolutionContext): ResolvedRef | null;
  claimsReference?(name: string): boolean;      // opt a name past the "no symbol exists" pre-filter
  extract?(filePath: string, content: string): FrameworkExtractionResult; // {nodes: Node[], references: UnresolvedRef[]}
  postExtract?(context: ResolutionContext): Node[]; // cross-file finalize; returns mutated nodes (id/qualifiedName preserved), persisted via updateNode
}
// frameworks/index.ts
function getAllFrameworkResolvers(): FrameworkResolver[];
function getFrameworkResolver(name: string): FrameworkResolver | undefined;
function detectFrameworks(context: ResolutionContext): FrameworkResolver[];   // filter by detect(), try/catch each
function getApplicableFrameworks(detected: FrameworkResolver[], language: Language): FrameworkResolver[];
function registerFrameworkResolver(resolver: FrameworkResolver): void;        // replace-by-name then push
// callback-synthesizer.ts
async function synthesizeCallbackEdges(queries: QueryBuilder, ctx: ResolutionContext): Promise<number>; // count inserted
// cargo-workspace.ts
function getCargoWorkspaceCrateMap(context: ResolutionContext): Map<string, string>;
// laravel.ts
const FACADE_MAPPINGS: Record<string, string>; // Auth→'Illuminate\\Auth\\AuthManager', Cache, Config, DB, Event, File, Gate, Hash, Log, Mail, Queue, Redis, Request, Response, Route, Session, Storage, URL, Validator, View
```

`ResolvedRef.resolvedBy` for all framework hits is the literal string `'framework'`. `Edge.provenance` enum: `'tree-sitter' | 'scip' | 'heuristic'`; all synthesized edges use `'heuristic'`.

**Pipeline wiring (consumers):**
- `extraction/tree-sitter.ts` runs `fw.extract(filePath, source)` after language extraction for every detected framework applicable to the file's language (errors → per-file warning, never fatal); nodes append to extraction result, references to `unresolvedReferences`.
- `resolution/index.ts` `initialize()` → `detectFrameworks`. `resolveOne()` pre-filter: a ref with no matching symbol name, no import match, and no `claimsReference` hit is dropped. Strategy 1 iterates frameworks in registry order calling `resolve()` through `gateFrameworkLanguage` (drops `references`/`imports` results crossing two known language families; `calls` and config↔code bridges pass); confidence ≥ 0.9 returns immediately, else the result is a candidate competing on max confidence with import and name-matcher strategies. `function_ref` refs never reach frameworks.
- `runPostExtract()`: after every indexAll and every incremental sync, calls each `postExtract`, persists via `queries.updateNode`, clears caches; per-framework try/catch.
- `resolveAndPersistBatched()` tail: `synthesizeCallbackEdges` (try/catch, best-effort; count reported as `stats.byMethod['callback-synthesis']`). Runs only on the batched (full-index) path — incremental sync does not re-run synthesis (known gap, doc'd in callback-edge-synthesis.md "Remaining work #2").

## Key algorithms & data flow

**All extractors are regex-over-comment-stripped source** (`stripCommentsForRegex(content, lang)` blanks comments and string bodies with spaces so byte offsets are line-stable), never AST. Line = `safe.slice(0, match.index).split('\n').length` (1-based).

### Framework resolvers (per the ~15 requested)

- **Express** (`express`, langs js/ts). Detect: package.json deps `express|fastify|koa|hapi`; else any file whose path contains `routes|controllers|middleware` and whose content includes `express`/`app.get`/`router.get`. Extract (files `\.(m?js|tsx?|cjs)$`): head regex `\b(app|router)\.(get|post|put|patch|delete|all|use)\s*\(\s*['"]([^'"]+)['"]\s*,`; `use` requires path starting `/`. Route node id `route:${file}:${line}:${METHOD}:${path}`, name `${METHOD} ${path}` (method uppercased), qualifiedName `${file}::${METHOD}:${path}`. Args = balanced parens (string-aware `matchDelim`). If args contain `=>`: inline handler — scan arrow body `\b([A-Za-z_$][\w$]*)\s*\(` and emit one `calls` ref per unique name not in `RESERVED_CALLS` (a 60-ish set: json, jsonp, send, sendStatus, sendFile, status, end, redirect, render, set, get, header, type, format, attachment, download, cookie, clearCookie, append, location, vary, links, accepts, is, next, then, catch, finally, resolve, reject, all, race, map, filter, forEach, reduce, find, push, pop, slice, splice, includes, keys, values, entries, assign, parse, stringify, log, error, warn, info, String, Number, Boolean, Array, Object, Date, Math, JSON, Promise, require, fail). Else: last comma-arg's tail identifier → one `references` ref. Resolve: middleware names (`^auth$`, `^authenticate$`, `^authorization$`, `^validate`, `^sanitize`, `^rateLimit`, `^cors$`, `^helmet$`, `^logger$`, `^errorHandler$`, `^notFound$`, `Middleware$`, all `/i`) conf 0.8; `^(\w+)Controller\.(\w+)$` conf 0.85; `^(\w+)(Service|Helper|Utils?)\.(\w+)$` conf 0.8.
- **Laravel** (`laravel`, php). Detect: file exists `artisan` or `app/Http/Kernel.php`. Claims `^[A-Za-z_][A-Za-z0-9_]*Controller@\w+$`. Extract: `Route::(get|post|put|patch|delete|options|any)\(…\)` → route (`name` = `${VERB} ${path}`); handler expr parsed: `[Class::class,'m']` → ref name `Class@m`, `'Ctrl@m'` → `Ctrl@m` (namespace stripped via last `\\` segment), `Class::class` → `Class`; closure → none. `Route::(resource|apiResource)('name', Ctrl::class)` → route id `route:…:RESOURCE:${name}`, name `resource:${name}`, ref kind `imports`. Resolve: `Model::method` — look in `app/Models/{C}.php` then `app/{C}.php`, method first, class fallback (conf 0.85); facade/helper names return null (external); `Controller@method` — `app/Http/Controllers/{C}.php` then any class named C in a path containing `Controllers` (conf 0.9 → returns immediately).
- **Rails** (`rails`, ruby). Detect: Gemfile contains `'rails'`, or `config/application.rb` / `app/controllers/application_controller.rb` / `config/routes.rb` exists. Claims `^[\w/]+#\w+$`. Extract: explicit `\b(get|post|put|patch|delete|match)\s+['"]p['"]\s*(?:,\s*to:\s*|=>\s*)['"]c#a['"]` → route + ref `c#a`; `resources? :name [only:/except:]` expands via `RESTFUL_ROUTES` — index GET `/r`, create POST `/r`, new GET `/r/new`, show GET `/r/:id`, edit GET `/r/:id/edit`, update PATCH `/r/:id`, destroy DELETE `/r/:id`; `resource` (singular) omits index and pluralizes the controller (naive: `y→ies`, `s|x|z|ch|sh→+es`, else `+s`). Route id `route:…:${VERB}:${ctrl}#${action}` for resources. Resolve Pattern 0 `c#a` → `app/controllers/${c}_controller.rb` method, fallback camelized `XController` class file (conf 0.85, returns null if miss — no fallthrough); Model `^[A-Z][a-zA-Z]+$` via snake-cased `app/models/…` (0.8); `*Controller` (0.85), `*Helper` (module kind, 0.8), `*Service|*Job` (0.8).
- **Django** (`django`, python). Detect: `django` (case-insensitive) in requirements.txt/setup.py/pyproject.toml, or `manage.py` exists. Extract: `\b(path|re_path|url)\s*\(\s*r?['"]([^'"]+)['"]\s*,\s*([\w.]+(?:\s*\([^)]*\))?)`; route id `route:${file}:${line}:${urlPath}`, name = raw url string; handler: `include('x.y')` → ref kind `imports` name `x.y`; else strip `.as_view(...)`/trailing call, take last dotted segment → `references`. - **Flask** (`flask`, python). Detect: `\bflask\b/i` in requirements/pyproject/Pipfile/setup.py; else first 50 files matching `(?:^|\/)(app|application|main|wsgi|__init__)\.py$` containing `\bFlask\s*\(` plus a flask import. - **Spring** (`spring`, langs java/kotlin/yaml/properties). Detect: `spring-boot|springframework` in pom.xml/build.gradle(.kts), else `@SpringBootApplication|@RestController|@Service|@Repository` in any `.java`. Claims `*:prefix`. Extract: `\b\w+\.(GET|POST|PUT|PATCH|DELETE|OPTIONS|HEAD|Get|Post|Put|Patch|Delete|Handle|HandleFunc)\s*\(\s*"([^"]+)"\s*,\s*([^)]+)\)` — receiver is ANY identifier (group vars); `Handle|HandleFunc` → method `ANY`; ref = tail identifier of the handler expr. ### Synthesizers (`synthesizeCallbackEdges` passes)

Ordering: Go `contains`+`implements` pre-passes are synthesized **and inserted first** (interface-dispatch reads them); all other passes collect edges, then merge with cross-pass dedupe on `source>target`, insert in 2000-row chunks with cooperative yields. Passes are language-gated by `queries.getDistinctFileLanguages()`. Every pass caps and dedupes internally; all edges `provenance:'heuristic'`.

1. **Callback/field observer** (`fieldChannelEdges`). Scan all method/function nodes (streamed, `iterateNodesByKind` — O(1) memory, #610). Registrar name `^(on[A-Z]\w*|subscribe|addListener|addEventListener|register|watch|listen|addCallback)$` AND body has `this\.(\w+)\.(?:add|push|set)\(` (captures field F). Dispatcher name matches `(emit|trigger|notify|dispatch|fire|publish|flush)/i` AND body has `\bof\s+(?:Array\.from\(\s*)?this\.(\w+)` plus some call, or `this\.(\w+)\.forEach\(`. Pair registrar↔dispatcher by **same file + same field**. For each incoming `calls` edge to the registrar, read the caller's source line and regex `${registrarName}\s*\(\s*(?:this\.)?(\w+)` to recover the argument; resolve by name to method|function. Emit dispatcher→callback, kind `calls`, `metadata: { synthesizedBy: 'callback', via: registrarName, field, registeredAt: '${callerFile}:${line}' }`. Cap `MAX_CALLBACKS_PER_CHANNEL = 40` per registrar. Flow example (excalidraw): `triggerUpdate → triggerRender` via `Scene.onUpdate(this.triggerRender)`; makes `mutateElement→…→render` connect.
2. **EventEmitter** (`eventEmitterEdges`). File scan with substring pre-gates (`.emit(|.fire(|.dispatchEvent(` / `.on(|.once(|.addListener(`). `EMIT_RE = /\.(?:emit|fire|dispatchEvent)\(\s*['"]([^'"]+)['"]/g`; dispatcher = tightest enclosing method/function/component node of the emit line. `ON_RE = /\.(?:on|once|addListener)\(\s*['"]([^'"]+)['"]\s*,\s*(?:function\s+(\w+)|(?:this\.)?(\w+))/g` — **named handlers only**; handler node by name (function|method). Correlate by event literal; skip any event with > `EVENT_FANOUT_CAP = 6` dispatchers or handlers (generic names like `error`). Edge metadata `{ synthesizedBy: 'event-emitter', event, registeredAt: '${file}:${line-of-on}' }` (no `line` field). Example: express `use → onmount` for `emit('mount')`/`on('mount', function onmount…)`.
3. **React re-render** (`reactRenderEdges`). For each `class` node: children = `contains`-edge targets of kind method; require a child named `render`; every other sibling whose body matches `this\.setState\s*\(` gets edge sibling→render, metadata `{ synthesizedBy: 'react-render', via: 'setState', registeredAt: '${renderFile}:${renderStartLine}' }`, `line` = sibling.startLine. Cap 40/class. Over-approximation accepted (reachability-correct).
4. **JSX child** (`reactJsxChildEdges`). Any file containing `</` or `/>`; for each method/function/component node whose slice also contains JSX markers, collect tag names `/<([A-Z][A-Za-z0-9_]*)[\s/>]/g`; resolve each name to a component|function|class node (`getNodesByName(...).find`); emit parent→child `calls`, metadata `{ synthesizedBy: 'jsx-render', via: tagName }` (**no registeredAt**), `line` = parent.startLine. Cap `MAX_JSX_CHILDREN = 30` per parent. Completes the flow `render → StaticCanvas → renderStaticScene`; shipping react-render without this hop measurably *raised* reads (partial coverage worse than none).
5. **Django ORM descriptor** — NOT a synthesizer: implemented as `djangoResolver.claimsReference('_iterable_class')` + `resolve()` → `ModelIterable.__iter__` (see above). Edge is a normal resolved `calls` ref (`resolvedBy:'framework'`, conf 0.7, not `heuristic` provenance). The playbook documents this asymmetry: named ref → resolver; no ref → synthesizer.

Other passes (same shape; `synthesizedBy` values are contract): `closure-collection` (Swift/Kotlin only, gate `(\w+)\.forEach\s*\{\s*(?:\$0|it)\s*\(`, registrars `.append/.add/.push/.insert` incl. `.write { $0.append }`, global pairing by field, cap `CC_FANOUT_CAP = 8`, dispatcher→registrar direction), `flutter-build` (`setState(` → `build` in `.dart`), `arkui-state` / `arkui-emitter` (cap 8; numeric keys same-file, named keys per workspace-module) / `arkui-route` (`/src/main/ets/${url}.ets` + `@Entry` struct), `cpp-override` (base method → same-name subclass method via `extends`), `interface-impl` (same for `implements`/abstract, langs java, kotlin, csharp, typescript, javascript, swift, scala, go, rust, arkts), `go-implements` (structural method-name-set match, kind `implements`, skips empty interfaces), `go-contains` (cross-file method→receiver-struct, same package dir), `kotlin-expect-actual`, `go-grpc-stub-impl`, `vue-handler`+`jsx-render` from Vue SFC templates (kebab→Pascal, Nuxt dir-prefixed auto-import names with prefix-collapse dedupe, `@click="fn"` handlers incl. composable destructure `const {close: x} = useY()`), `sveltekit-load`, `rn-event-channel` (ObjC `sendEventWithName:@"E"`, Swift `sendEvent(withName: "E"`, JVM `.emit("E",`, wrapper `sendEvent(...)"E"` → JS `addListener` named handlers), `fabric-native-impl`, `expo-cross-platform`, `rn-cross-platform`, `mybatis-java-xml`, `gin-middleware-chain`, `pascal-form`, `redux-thunk`, `object-registry`, `rtk-query`, `pinia-store`, `vuex-dispatch`, `celery-dispatch`, `spring-event`, `mediatr-dispatch`, `sidekiq-dispatch`, `erlang-behaviour`, `laravel-event`, `fn-pointer-dispatch` (c-fnptr-synthesizer.ts), `goframe-route` (goframe-synthesizer.ts), `nix-option-path`.

## Wire/contract surfaces

- **Route node shape** (kind `route`, in `NodeKind` enum): `id` formats are load-bearing per framework — `route:${file}:${line}:${METHOD}:${path}` (express/laravel/rails-explicit/spring/go/rust/csharp/flask/fastapi), `route:${file}:${line}:${path}` (django path()/react), `route:${file}:${line}:VIEWSET:${prefix}`, `route:…:RESOURCE:${name}`, `route:…:ANY:${path}`, `route:${file}:${path}:${line}` (Next.js — note transposed order), `route:${file}:${path}:1` (SvelteKit/Nuxt). `name` is agent-visible: `"${METHOD} ${path}"` (uppercased verb, single space) or bare path for path-only routers; `"VIEWSET /x"`, `"resource:x"`, `"ANY /x"`, `EVENT|MESSAGE|WS|QUERY|MUTATION|SUBSCRIPTION` verbs for NestJS. `qualifiedName` `${file}::${METHOD}:${path}` or `${file}::route:${path}` (varies per framework as shown above — keep exact).
- **Synthesized-edge metadata contract**: `provenance:'heuristic'`, `metadata.synthesizedBy` ∈ {`callback`, `closure-collection`, `event-emitter`, `react-render`, `flutter-build`, `arkui-state`, `arkui-emitter`, `arkui-route`, `cpp-override`, `go-implements`, `kotlin-expect-actual`, `interface-impl`, `go-grpc-stub-impl`, `jsx-render`, `vue-handler`, `rn-event-channel`, `expo-cross-platform`, `rn-cross-platform`, `fabric-native-impl`, `mybatis-java-xml`, `gin-middleware-chain`, `pascal-form`, `sveltekit-load`, `redux-thunk`, `object-registry`, `rtk-query`, `pinia-store`, `vuex-dispatch`, `celery-dispatch`, `spring-event`, `mediatr-dispatch`, `sidekiq-dispatch`, `nix-option-path`, `erlang-behaviour`, `laravel-event`, `fn-pointer-dispatch`, `goframe-route`}; plus `via` / `event` / `field` and `registeredAt: 'file:line'` (the wiring site — surfaced verbatim in explore Flow and node trails; MCP layer depends on these keys). Edge dedupe key is `source>target` across all passes (first pass wins).
- **Resolution contract**: framework results carry `resolvedBy:'framework'`; conf ≥ 0.9 short-circuits; exact confidence constants above matter because they compete with import (0.9/0.95) and name-matcher scores. `claimsReference` names: `_iterable_class`, `*.urls`, `*Controller@method`, `[\w/]+#\w+`, `*:prefix`.

- **Doc reconciliation**: `callback-edge-synthesis.md` matches the code including its recorded divergences (file+field pairing instead of class; regex arg recovery instead of tree-sitter; `heuristic` provenance instead of a `callback-synthesis` enum value; fan-out caps instead of confidence tiers). ## Rust port notes

- **Crate placement**: `FrameworkResolver` trait + registry + all `frameworks/*` → `selene-resolve`; synthesizers (`callback-synthesizer` et al.) → `selene-resolve` too (they are whole-graph passes over `GraphStore`, invoked after base resolution — they need `iterateNodesByKind`-style streaming, `getIncomingEdges`, `insertEdges` batching on the `GraphStore` trait, so budget those primitives before freezing it, per PRD §5.4). `strip-comments` and the pure name-math (`swift-objc-bridge`, cargo-toml parsing) are dependency-free utility modules. Route-node emission happens in the *extraction* phase (tree-sitter.ts calls `fw.extract`) — in Selene that is a `selene-extract` ↔ `selene-resolve` seam: the framework registry must be callable from the extractor with just `(filePath, content)`.
- **Regex portability**: all patterns are ECMAScript. Watch: `regex` crate lacks backreferences (none used) but also lacks lookahead — `=(?!=)` (arkui mutation), `[^C]` hack in UIKit's `UIView[^C]`, and `(?:…)?` non-greedy windows are used; `fancy-regex` or hand-rolled scanning needed for the lookahead. `lastIndex` reset semantics (module-level `g` regexes are shared and manually reset — a latent TS footgun) disappear naturally in Rust; make regexes `static` `Lazy` and iterate matches.
- **TS idioms to redesign**: `ResolutionContext` is a fat optional-method interface (`?` methods with caller fallbacks) — in Rust make them required trait methods with default impls, or split into core + extension traits. `WeakMap`-keyed cargo cache → per-resolver-instance `OnceCell`. `Date.now()` `updatedAt` stamps on nodes are part of the Node shape. Metadata is `Record<string, unknown>` serialized to JSON in the `edges.metadata` column — keep as `serde_json::Value` to preserve exact keys.
- **Bugs/dead code observed** (don't faithfully port): `goImplementsEdges` has a duplicated `(++scanned255 & 63)` yield block (lines 852–854); express `RESERVED_CALLS` lists `redirect` twice; `java.ts` lines 82–87 contain an empty `if` body (dead condition kept as a comment); react's Next.js `app/` route uses `filePath.includes('page.')` (matches `mypage.tsx` — looser than the pages/ segment check); axum emits one route node per chained verb but the id omits the verb-specific column so `get(h).post(h)` on one line dedupes only by METHOD-in-id (ids differ, fine — but `endColumn: 0` unlike other extractors); `vueResolver` has no `languages` list so its (path-only) extract runs for every language of file. Rails `pluralize`/`camelize` are deliberately naive — port as-is, they're a compat contract with existing IDs.
- **Perf lessons carried in code comments (preserve as invariants)**: never materialize all nodes of unbounded kinds (#610/#1212 OOM) — stream; language-gate every pass via distinct file languages (#1212); pre-gate expensive regex scans with cheap `contains` checks and language sets (#1235 — ungated `.push(` scanning cost 20+ min on PHP/JS); line-of-offset must be indexed, not `slice().split()` per match; chunk edge inserts (2000) with yields. In Rust the cooperative-yield machinery is unnecessary (no single-threaded event-loop watchdog) but the batching/streaming discipline still matters.
- **Precision doctrine (from docs + code, must survive the port)**: fan-out caps (6 events / 8 fields / 8 emitter keys / 40 callbacks / 30 JSX children) instead of type inference; named-handlers-only; ambiguous → drop, never guess (`candidates.length !== 1 continue`); partial flow coverage is worse than none — bridge a boundary only together with the hops that complete the canonical flow, then re-measure.
